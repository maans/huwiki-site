Privacy policy

Working draft · 26 October 2026

Important: This is a working draft, not the final reviewed privacy policy for HUWiki. The current OAuth scopes, integrations, storage, deletion features, and any external services must be verified before this becomes the official policy or is submitted for Google's OAuth verification.

This public information website

This site is a static website hosted on GitHub Pages. Its own code contains no advertising, analytics, or data-collection forms. GitHub may process technical visitor data as part of hosting; see GitHub's privacy statement.

The HUWiki application

HUWiki runs separately through Google Apps Script and uses Google account authentication and Google Drive features. Wikis can be stored and shared within the user's Google environment. The four permissions in the current OAuth preview are listed below.

Integrations and sharing

HUWiki is being developed with optional extensions and integrations. Any use of external services, including AI providers, will be documented after the behaviour of the current release is verified. Users should avoid putting sensitive information into preview wikis until those details have been documented.

Access, retention and deletion

The reviewed version of this policy will describe the exact storage locations, sharing controls, logging, retention periods, and deletion capabilities. Please contact the project if you have questions.

Google data

Google accounts and Google Drive are also subject to Google's own terms and privacy policy. See Google's privacy policy.

Permissions in the OAuth preview

This draft describes the OAuth preview linked from this website. Other HUWiki editions may request different permissions.

  • Selected Drive files (drive.file): create and work with files made by, or explicitly opened with, HUWiki. This is not permission to read every file in your Drive.
  • External connections (script.external_request): call Google APIs and retrieve resources used by enabled features.
  • Send email (script.send_mail): send wiki sharing invitations. This permission does not allow HUWiki to read your inbox.
  • Read calendars (calendar.readonly): read calendars and events for calendar features. It does not grant permission to change your Google Calendar events.

Storage and deletion: implementation checked

Wiki content and supporting files use Google Drive, including spreadsheets used as indexes. Apps Script user properties and caches store application settings and temporary state. Browser storage is also used for cached navigation and AI connection settings.

The wiki deletion code moves the wiki data folder to Drive Trash and marks its registry entry as deleted. This is not immediate permanent deletion of every record. Copies, exported files and separately published sites require separate attention.

Optional AI features

AI features connect to the model service selected by the user, including local model servers and supported cloud providers. Requests can contain conversation text, selected wiki context and attached images. Saved conversations become wiki content and must be considered when sharing a wiki. Provider-specific data handling and the complete credential storage and deletion flow still require review before this policy is final.

Still to be confirmed before submission

We must finish the review of logging, retention periods, optional integrations, published copies, support access and Google user-data policy compliance. The statements above are based on a source review on 26 October 2026; they do not mean Google has approved the app.
