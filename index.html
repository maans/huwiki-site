Your wiki. Your ideas. More possibilities.

HUWiki helps people create, organise, and share TiddlyWikis in an environment built with Google Apps Script and Google Drive.

Built on TiddlyWiki, created by Jeremy Ruston and a worldwide community.

Limitations · Google’s daily quota and local copies

When HUWiki reaches Google’s daily quota

Seeing HU_SYNC_DAILY_QUOTA or a message about the daily UrlFetch quota? Google’s request limit can interrupt loading and saving to Drive.

Keep the wiki tab open. Avoid reloading it or reopening the wiki in another tab until you’ve secured your changes. Even with a copy stored in the browser, HUWiki must first confirm your access with Google. The quota limit can block that check.

  1. Save what you have open. If Save changes downloads an HTML file, check that the file contains your new work. It can save content from the open wiki. Attachments cached separately and the local change log aren’t automatically included. If you can’t get a usable download, copy the new text to a local file. Treat changes as saved to Drive once sync is confirmed.
  2. Download a recovery ZIP from Local copies if one is available. Use the HUWiki dashboard if you can access it with the same Google account and browser profile. The ZIP uses a previously stored version of the wiki, attachments HUWiki has retained for it, and a separate change log you can review. Some content may be missing. Keep the site’s browser data to preserve the local material.
  3. Use the regular ZIP download when Drive is available. The download next to a wiki on the dashboard uses the saved version and file list on Drive. It can reuse cached attachments that match the Drive version and include local changes in a separate log.

Continue with an existing co-editor

If you already share the wiki with another account as an editor, that account can continue from the shared version on Drive while it still has access and quota available. This can be a personal Google account and a Workspace account, for example. Each account uses its own UrlFetch quota regardless of who owns the wiki. Preserve any changes that exist only in the first browser there.

Ownership determines where the shared wiki is stored and who manages sharing. Work or school accounts may be subject to rules about sharing outside their organisation. Google’s guide to sharing in Drive.

Google resets the quota 24 hours after the first request in the quota window. Try syncing after the reset and check that your latest changes are there. The daily limit is lower for personal accounts than for Workspace accounts. See Google’s Apps Script quotas.
